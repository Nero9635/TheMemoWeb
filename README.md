# The Memo for iPhone / iPad(Web アプリ / PWA)

Android 版「The Memo」の iPhone / iPad 版です。**iPad mini の縦画面**(幅 744pt)を主な対象にしています。
幅 700pt 以上では、画面の真ん中に読みやすい幅の列を置き、文字・カレンダー・押せる場所を一回り大きくし、
シートやメニューは画面の中ほどに浮かべます。iPhone の幅でもそのまま使えます。
iPad でキーボードをつないでいる時は **⌘ + Return** で投稿・送信できます。

## 言語・文字の大きさ・エディタ(v7〜)

- **言語**: 設定 → Language で English(既定)/ 日本語 / 简体中文。画面の言葉は `js/i18n.js` にまとめてある(新しい文言は3言語ぶん足す)。
- **文字の大きさ**: 設定 → Text size(S / M / L / XL)。CSS の `font-size: calc(Npx * var(--ts))` で全体が拡大縮小する。
- **ブロックエディタ**(`js/editor.js`): 見出し1/2・箇条書き・番号付き・ToDo・引用・区切り線・写真。
  行頭で `# ` `## ` `- ` `1. ` `[] ` `> ` `---`、空のブロックで `/` を打つとメニュー。下のツールバーの **Aa** でも形式の変更・移動・削除ができる。
  データの形は Android 版と同じ(区切り線は Android では「---」の段落として見える)。
- **見た目**: iOS 26/27 の Liquid Glass に寄せたガラス素材(`.glass`)、浮かぶ入力欄とツールバー、角の大きな丸み。

## v8 の追加

- **日記カード**: タイムラインの日記は紙のような特別なカード(DIARY ラベル・曜日・気分)。
- **気分**: 日記の編集画面の上で 8 つから選ぶ(もう一度押すと外す)。タイムラインのカードとカレンダーにも出る。`memo.mood` に保存(Android 版は無視するだけで壊れない)。
- **返信(X のような会話)**: 投稿の下に自分の返信を書ける。「返信して 〇〇 に聞く」で人物が返事をする。各返信の … から「返事をもらう」「削除」。会話は `memo.chat`(Android 版の会話と同じ場所)。
- **本文の書体**: 設定 → Writing font(標準 / 明朝)。自分の書いた文字だけが変わる。
- v9: 返信欄は吹き出しボタンで出し入れ(ふだんは隠す)。気分は日記の上の小さなカプセルを押して選ぶ。書くための道具(Aa・写真・タグ・Words)はスクロールしても下に残り、一番下ではボタン列の上に止まる。
- 指 2 本での拡大縮小を止めた。バックアップは「Back up everything」だけ。

## タグと #ハッシュタグ

| | タグ | #ハッシュタグ |
|---|---|---|
| 何か | 決まった分類(初期: アイデア・散歩・やること・気づき・作品・日記) | 本文に「#銀杏」のように書く自由な言葉 |
| 数 | 自分で決めた一覧だけ(設定 → Tags で追加・名前・色・並び・削除) | いくつでも |
| AI | 「Title & tags」はこの一覧の中からだけ選ぶ(新しいタグは作らない) | AI は 0〜3 個を提案し、本文の最後に足す |
| 探す | 検索画面のタグのチップ | 本文の #言葉 を押す、または検索に「#言葉」 |

投稿に付いているのに一覧にないタグ(以前の版や Android 版の AI が作ったもの)は、
設定 → Tags の「NOT IN THE LIST」で、一覧に入れる / ハッシュタグに変える(→ #)/ 外す を選べます。

---

以下は全体の説明です。Mac なしで作れる **Web アプリ(PWA)** として作っています。
iPhone の Safari で開いて「ホーム画面に追加」すると、アプリのように全画面で起動し、オフラインでも開けます。

- データ(メモ・写真・設定)は **iPhone の中だけ**(IndexedDB)に保存されます。サーバーには送りません。
- AI は Android 版と同じく、自分の Gemini APIキーで直接呼びます(✦ / Ψ を押した時だけ)。
- バックアップの zip は **Android 版と同じ形式**。Android のバックアップをそのまま読み込めます(逆も可)。

## フォルダの中身

| 場所 | 役割 |
|---|---|
| `index.html` | 入口 |
| `manifest.webmanifest` / `icons/` | ホーム画面に追加した時の名前とアイコン |
| `sw.js` | オフラインで開くための仕組み。**ファイルを変えたら `VERSION` を上げる** |
| `css/app.css` | 見た目(iOS 風、ライト / ダーク) |
| `js/app.js` | 画面の切り替え・共通ダイアログ |
| `js/home.js` | ホーム(カレンダー + タイムライン + 入力欄) |
| `js/detail.js` | 投稿の詳細・気分・返信欄(人物との会話) |
| `js/settings.js` | 設定・AIの人物・検索・ゴミ箱・簡単ワード |
| `js/ui.js` / `js/icons.js` | 共通部品(シート・メニュー・アバターなど)とアイコン |
| `js/store.js` | 状態とすべての操作(Android 版の MainViewModel にあたる) |
| `js/ai.js` | Gemini の呼び出しとプロンプト(Android 版と同じ文面) |
| `js/backup.js` | バックアップ・復元・年ごとの保管 |
| `js/db.js` | 端末内の保存(IndexedDB) |
| `vendor/` | Preact + htm(画面部品)、JSZip(zip)。ライセンスも同梱 |
| `tools/make_icons.py` | アイコン画像を作り直すスクリプト |

ビルド作業はありません。ファイルをそのまま置けば動きます。

## iPhone で使う(公開の手順)

iPhone でホーム画面のアプリとして使うには、**https のアドレス**に置く必要があります。無料の方法の例:

### GitHub Pages(おすすめ)
1. GitHub で新しいリポジトリを作る(例: `thememo`)。
2. このフォルダの中身をすべてアップロードする(GitHub Desktop か、ブラウザの「Add file → Upload files」)。
   `.claude/` フォルダは入れなくてよい。
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save。
4. 数分後に `https://<ユーザー名>.github.io/thememo/` で開けるようになる。

※ 無料プランではリポジトリ(=アプリのプログラム)が公開されます。**メモのデータや APIキーはプログラムに含まれない**ので、公開されるのはアプリの仕組みだけです。

### iPhone に入れる
1. iPhone の **Safari** で上のアドレスを開く。
2. 共有ボタン → **「ホーム画面に追加」**。
3. ホーム画面のアイコンから起動 → 設定(⚙)で名前と Gemini APIキーを入れる。

### 大事な注意
- **必ずホーム画面から使う**。Safari のタブのまま使うと、しばらく開かない時に iPhone がデータを消すことがあります(ホーム画面に追加したアプリは対象外)。
- それでも念のため、ときどき **設定 → Back up everything** で zip を「ファイル」や Google ドライブに保存してください。
- プログラムを更新したら `sw.js` の `VERSION` を上げてからアップロードする。iPhone は次に開いた時(電波のある時)に新しい版になります。

## Android 版との違い(Web でできないこと)

| 機能 | iPhone 版 |
|---|---|
| ホーム画面のウィジェット・通知のリマインダー | なし |
| 歩数(ヘルスケア)・天気・場所の自動記録 | なし(Android から読み込んだ値は表示する) |
| リンクのプレビュー(題名・画像のカード) | サイト名だけのカード(ブラウザの制限で他サイトの中身を読めないため) |
| 送信時の振動 | iPhone の Safari は非対応 |
| 編集画面の見出し・箇条書きの書式ボタン | なし(1つの文章欄。Android の箇条書きは「・」付きの文字として表示) |
| 音声入力 | 入力欄のマイク(Safari の音声認識)。キーボードのマイクも使える |
